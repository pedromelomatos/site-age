# 💰 AGE Gold Soluções Financeiras

Site institucional desenvolvido para a **AGE Gold Soluções Financeiras**, com foco em apresentar os principais serviços financeiros oferecidos pela empresa e facilitar o contato com clientes interessados.

Acesse o site: https://grupoagegold.com.br/
---

## 🌐 Visão Geral

O projeto é um site responsivo e leve, criado com **HTML, CSS e JavaScript puros**, sem dependências externas, garantindo desempenho rápido e compatibilidade com qualquer hospedagem, como HostGator ou GitHub Pages.

Cada serviço possui sua própria página, com banner personalizado, explicação detalhada, vantagens e um botão de contato que leva diretamente ao **WhatsApp da empresa**.

## ⚙️ Tecnologias Utilizadas

## 🚀 Publicação

O conteúdo hospedado no **HostGator** está localizado na pasta:

```
/site
```

Cada arquivo HTML é independente, bastando enviar essa pasta diretamente para o diretório público da hospedagem (ex: `public_html`).
